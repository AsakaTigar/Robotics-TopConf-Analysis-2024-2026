## 1. Audit Methodology

Automated rule-based scan on `Authors`, `Affiliation`, and `Paper Link` columns combined with manual verification on pattern hits. An entry is flagged `DATA_QUALITY=PLACEHOLDER_AUTHORS` if it satisfies **2+ of**:

1. Authors exactly match canonical placeholder names (English or Chinese):
   - EN: `John Doe`, `Jane Smith`, `Bob Smith`, `Alice Johnson`, `David Brown`, `Maria Garcia`, `Lisa Wang`, `Alex Chen`
   - CN: `张三 Zhang San`, `李四 Li Si`, plus all 2-character family+given 2-person pairs exactly of form `(Family Given); (Family Given)` × no affiliation × NA on all other metadata = batch-insertion signal
2. Affiliation == `N/A` AND `Paper Link == NA AND `Code Link == NA
3. Robot Type has obvious mismatch (e.g. Hexapod paper classified as 四足机器人) combined with signal #1 and #2

Separately, an entry is flagged `DATA_QUALITY=REVIEW` if it carries one concern but is not a full placeholder (author looks real but venue is 2025 unindexed / truncated 20-author list / classification debatable).

## 5. Fixes Applied to Main CSV

All fixes are **non-destructive** — no data rows deleted. Only `Notes` column enriched with:

- `DATA_QUALITY=PLACEHOLDER_AUTHORS` — suppresses author rendering visually in README by future build_readme.py enhancement (currently: authors still rendered but DQ badge added on build)
- `AUDIT_REF=<code>` — for cross-reference to this document
- Brief one-line rationale included so future manual edits can understand signal

No author names were overwritten — even placeholder names, because we can't guarantee what the correct ones are; only SRL Workshop-verified papers carry cross-reference.
